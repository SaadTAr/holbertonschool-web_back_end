# Python - Async Comprehension

This project focuses on asynchronous generators and asynchronous comprehensions in Python.

## Learning Objectives

By completing this project, I learned:

- How to write asynchronous generators
- How to use `yield` with async functions
- How to use asynchronous comprehensions
- How to run asynchronous operations in parallel
- How to measure the runtime of async functions
- How to use `asyncio.gather`

## Tasks

### 0. Async Generator
Create an asynchronous generator that yields 10 random numbers between 0 and 10 with a one-second delay between each value.

### 1. Async Comprehensions
Use an async comprehension to collect 10 values from the asynchronous generator.

### 2. Run time for four parallel comprehensions
Run four async comprehensions in parallel and measure the total runtime.
