# Python - Async Function

This project introduces asynchronous programming in Python using `async` and `await`.

## Learning Objectives

By completing this project, I learned:

- `async` and `await` syntax
- How to execute asynchronous coroutines
- How to run multiple coroutines concurrently
- How to use the `asyncio` module
- How to create asyncio tasks
- How to measure asynchronous runtime
- How concurrency improves execution time

## Tasks

### 0. The basics of async
Create an asynchronous coroutine that waits for a random delay and returns the delay.

### 1. Execute multiple coroutines at the same time
Run multiple `wait_random` coroutines concurrently and return their delays.

### 2. Measure the runtime
Measure the average execution time of concurrent coroutines.

### 3. Tasks
Create an `asyncio.Task` from the `wait_random` coroutine.

### 4. Tasks
Run multiple asyncio tasks concurrently and return their results.
