# ES6 Promises

This project covers asynchronous programming in JavaScript using ES6 Promises.

## Learning Objectives

- Understand Promises and how they work
- Create and return Promises
- Use `then`, `catch`, and `finally`
- Handle fulfilled and rejected Promises
- Use `Promise.all`
- Use `Promise.allSettled`
- Use `Promise.race`
- Handle errors with `throw`
- Use `try` and `catch`

## Tasks

### 0. Keep every promise you make and only make promises you can keep
Return a Promise from a function.

### 1. Don't make a promise...if you know you can't keep it
Resolve or reject a Promise depending on a boolean value.

### 2. Catch me if you can
Handle Promise resolution, rejection, and completion.

### 3. Handle multiple successful promises
Use `Promise.all` to handle multiple Promises.

### 4. Simple promise
Return a resolved Promise containing user information.

### 5. Reject the promises
Return a rejected Promise with an error.

### 6. Handle multiple promises
Use `Promise.allSettled` to handle multiple Promise results.

### 7. Load balancer
Use `Promise.race` to return the result of the first resolved Promise.

### 8. Throw an error
Throw an error when attempting to divide by zero.

### 9. Throw error / try catch
Use `try`, `catch`, and `finally` to handle function execution.
