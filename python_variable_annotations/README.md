# Python - Variable Annotations

This project introduces type annotations in Python 3.

## Learning Objectives

By completing this project, I learned:

- Type annotations in Python 3
- How to specify function signatures and variable types
- Duck typing
- How to validate code using mypy
- Complex type annotations using the typing module
- Callable types
- Iterable and Sequence types

## Tasks

### 0. Basic annotations - add
Write a type-annotated function that takes two floats and returns their sum.

### 1. Basic annotations - concat
Write a type-annotated function that concatenates two strings.

### 2. Basic annotations - floor
Write a type-annotated function that returns the floor of a float.

### 3. Basic annotations - to string
Write a type-annotated function that converts a float to a string.

### 4. Define variables
Define and annotate variables with int, float, bool, and str types.

### 5. Complex types - list of floats
Write a function that calculates the sum of a list of floats.

### 6. Complex types - mixed list
Write a function that calculates the sum of a list containing integers and floats.

### 7. Complex types - string and int/float to tuple
Write a function that returns a tuple containing a string and the square of a number.

### 8. Complex types - functions
Write a function that returns another function used as a multiplier.

### 9. Let's duck type an iterable object
Annotate a function that accepts an iterable of sequences and returns each sequence with its length.
