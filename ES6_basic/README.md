# ES6 Basics

This project introduces the main features of ECMAScript 6 (ES6).

## Learning Objectives

- Understand what ES6 is
- Use `const` and `let`
- Understand block scope
- Use arrow functions
- Use default function parameters
- Use rest parameters
- Use spread syntax
- Use template literals
- Use object property shorthand
- Use computed property names
- Use ES6 method properties
- Use `for...of` loops
- Work with iterators and objects
