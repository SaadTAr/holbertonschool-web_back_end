# ES6 Data Manipulation

This project focuses on data manipulation using modern JavaScript ES6 features.

## Learning Objectives

- Use `map`, `filter`, and `reduce` on arrays
- Work with typed arrays
- Understand the `Set` data structure
- Manipulate sets
- Understand the `Map` data structure
- Manipulate maps

## Tasks

### 0. Basic list of objects
Create an array containing student objects.

### 1. More mapping
Use `map` to retrieve student IDs.

### 2. Filter
Use `filter` to select students by location.

### 3. Reduce
Use `reduce` to calculate the sum of student IDs.

### 4. Combine
Combine `filter` and `map` to update student grades.

### 5. Typed Arrays
Create and manipulate an `ArrayBuffer` using `DataView`.

### 6. Set data structure
Create a Set from an array.

### 7. More set data structure
Check whether all values from an array exist in a Set.

### 8. Clean set
Manipulate Set values using a starting string.

### 9. Map data structure
Create a Map containing grocery items and quantities.

### 10. More map data structure
Update Map entries with a quantity of 1.
