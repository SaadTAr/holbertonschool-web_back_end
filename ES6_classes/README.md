# ES6 Classes

This project covers Object-Oriented Programming concepts in JavaScript using ES6 classes.

## Learning Objectives

- Define classes in JavaScript
- Add methods to classes
- Use getters and setters
- Use static methods
- Extend classes using inheritance
- Understand metaprogramming and symbols
- Implement computed method names
- Work with class constructors
- Understand class hoisting

## Tasks

### 0. You used to attend a place like this at some point
Implement a `ClassRoom` class with a `maxStudentsSize` attribute.

### 1. Let's make some classrooms
Create and return multiple `ClassRoom` objects.

### 2. A Course, Getters, and Setters
Implement a `HolbertonCourse` class using getters, setters, and type validation.

### 3. Methods, static methods, computed methods names
Implement a `Currency` class with getters, setters, and a method to display the full currency.

### 4. Pricing
Implement a `Pricing` class and a static method for converting prices.

### 5. A Building
Implement a `Building` class that requires subclasses to override an evacuation warning method.

### 6. Inheritance
Implement `SkyHighBuilding` by extending the `Building` class.

### 7. Airport
Implement an `Airport` class and customize its string tag.

### 8. Primitive - Holberton Class
Implement a `HolbertonClass` with custom primitive conversion behavior.

### 9. Hoisting
Fix class definitions and initialization while respecting JavaScript class hoisting behavior.

### 10. Vroom
Implement a `Car` class with a method that returns a new object of the same class.
