# NoSQL

This project introduces NoSQL databases using MongoDB.

## Learning Objectives

- Understand the meaning of NoSQL
- Understand the difference between SQL and NoSQL
- Understand ACID
- Understand document storage
- Understand NoSQL database types
- Understand the benefits of NoSQL databases
- Query information from a NoSQL database
- Insert, update, and delete information from MongoDB

## Files

- `0-list_databases` - Lists all databases
- `1-use_or_create_database` - Creates or uses the database my_db
- `2-insert` - Inserts a document
- `3-all` - Lists all documents
- `4-match` - Lists documents matching a name
- `5-count` - Displays the number of documents
- `6-update` - Updates matching documents
- `7-delete` - Deletes matching documents
